```ts
import { Http, envelope } from "fetchzen";
import { z } from "zod";

const schema = z.object({ name: z.string().trim() });
const api = Http.create(`${location.origin}/api/examples/`, {
  cache: false, secure: false, preset: envelope,
});
const result = await api.get("echo", { params: { name: "Ada" }, schema });
console.log(result.payload.name);
```

## What to notice

Try a name with surrounding spaces: the inferred payload contains the trimmed name,
without the echo response's extra fields. The numeric-name checkbox intentionally
requires a number instead of a string to produce `ERR_SCHEMA`.
The demo calls this site's bounded echo endpoint; use your own base URL in an application.
