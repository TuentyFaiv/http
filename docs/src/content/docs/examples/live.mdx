Choose one feature and inspect its result. Nothing is sent on page load.
These panels use this site's bounded `/api/examples/` API, not a production service.
Uploads are counted and discarded, not stored.

| Goal | Response mode |
| --- | --- |
| Read structured data | JSON (default) |
| Receive a file | `blob` |
| Consume bytes incrementally | `stream` |
