The package is ESM-only, with no runtime dependencies. Use Node.js 20+ or a modern
browser, Bun, Deno, or edge runtime that provides the standard Fetch APIs.

## Make a request

```ts
import { Http } from "@tuentyfaiv/http";

type User = { id: number; name: string };

const api = Http.create("https://api.example.com/v1", { cache: false });
const { payload, response } = await api.get<User>("/users/1");

console.log(payload.name, response.status);
```

Replace the URL with your API. The leading slash keeps the base path: this requests
`https://api.example.com/v1/users/1`. The generic describes the expected payload;
it does not validate the server's data. Use a [schema](../guides/validation/) for that.

The default `envelope` preset returns:

| Field | Meaning |
| --- | --- |
| `payload` | Parsed data, unwrapping the first non-null `data` or `payload` field. |
| `response` | A Fetch `Response`; JSON and text bodies are cloned by default so it remains readable. |
| `message` | A message selected by the preset, often the API's `message` or an empty string. |
| `success` | A preset-derived flag, **not** an alias for `response.ok`. An empty JSON array can produce `false` on HTTP 200. |

HTTP failures and recognized API failures reject the promise. Prefer
[`safe` methods](../guides/errors/) if you want an error/result tuple.
Use [`bare` or `rest`](../guides/presets/) if your API does not follow envelope conventions.

## Configure an instance

```ts
import { Http } from "@tuentyfaiv/http";

const api = Http.create("https://api.example.com/v1", {
	cache: false,
	headers: { "Accept-Language": "en-US" },
	params: { locale: "en-US" },
	timeout: 5_000,
	retry: 2,
});

await api.get("/health", { timeout: 1_000, retry: 0 });
```

Request headers and parameters override matching instance defaults. `timeout`,
`retry`, `secure`, `log`, and `errorMessage` can also be overridden per request.
Pass Fetch options such as `credentials` or `signal` on the request, not to `create`.

:::caution[Instance caching is not response caching]
`Http.create` caches by the exact base URL string by default. Calling it again with
that URL returns the original client and **ignores the new configuration**, including
a different preset or credentials. Use `cache: false` for server-side request isolation,
for tests, and whenever you need differently configured clients for the same URL.
This option is separate from Fetch's per-request `cache` option.
:::

## Without a base URL

```ts
import http from "@tuentyfaiv/http";

await http.get("https://api.example.com/health");
```

The default export has no base URL. Browser-relative endpoints also work; server
runtimes generally require an absolute URL.
