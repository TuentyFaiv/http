Elige una función e inspecciona el resultado. No se envía nada al abrir la página.
Los paneles usan la API acotada `/api/examples/` de este sitio, no un servicio de producción.
Los archivos se cuentan y descartan, no se almacenan.

| Objetivo | Modo de respuesta |
| --- | --- |
| Leer datos estructurados | JSON (predeterminado) |
| Recibir un archivo | `blob` |
| Consumir bytes incrementalmente | `stream` |
