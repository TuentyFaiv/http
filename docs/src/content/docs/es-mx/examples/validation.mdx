import { Http, envelope } from "fetchzen";
import { z } from "zod";

const schema = z.object({ name: z.string().trim() });
const api = Http.create(`${location.origin}/api/examples/`, {
  cache: false, secure: false, preset: envelope,

## Qué observar

Prueba un nombre con espacios alrededor: el contenido inferido incluye el nombre
sin esos espacios y elimina los campos extra de la respuesta. La casilla de nombre
numérico exige un número en lugar de texto para provocar `ERR_SCHEMA`.
La demo usa el endpoint echo de este sitio con límites; usa tu propia URL base en una aplicación.

Continúa con [transformaciones](../transforms/) o [errores seguros](../safe-errors/).
