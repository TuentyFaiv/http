Envía JSON al endpoint echo de demo de este sitio; reemplaza la URL base por tu API en una aplicación.

```ts
import { Http, envelope } from "fetchzen";
const api = Http.create(`${location.origin}/api/examples/`, {
  cache: false, secure: false, preset: envelope,
});
const result = await api.post("echo/", JSON.stringify({ name: "Ada" }));
console.log(result.payload);
```

## Qué observar

`envelope` extrae `data`; `bare` y `problem` conservan el cuerpo JSON.
Prueba GET y POST. El demo acotado solo devuelve los campos de texto `name` y `message`.
`secure: false` es para estos demos públicos, no una recomendación para APIs autenticadas.
