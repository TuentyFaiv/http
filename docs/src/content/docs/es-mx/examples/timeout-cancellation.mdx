Pasa una señal y un límite al endpoint de demo con demora de este sitio.

```ts
import { Http, envelope } from "fetchzen";
const api = Http.create(`${location.origin}/api/examples/`, {
  cache: false, secure: false, preset: envelope,
});
const controller = new AbortController();
// Llama controller.abort() desde tu control de cancelación.
try {
  console.log(await api.get("delay", {
    params: { ms: "1000" }, timeout: 500, signal: controller.signal,
  }));
} catch (error) {
  console.error(error);
}
```

## Qué observar

Un límite de 500 ms vence antes de una respuesta de 1000 ms. Auméntalo o cancela durante la espera.
El demo limita las demoras a 3000 ms. Cancelar detiene la espera del cliente, no el trabajo ya recibido por el servidor.
Usa tu propio endpoint fuera del demo.
