## Realiza una solicitud tipada

Ejecuta esto en un módulo TypeScript. El endpoint público devuelve un objeto JSON
sin envoltura, así que selecciona `rest` explícitamente:

```ts
import { Http, rest } from "fetchzen";

type User = { id: number; name: string };

const api = Http.create("https://jsonplaceholder.typicode.com", {
	preset: rest,
	cache: false,
});
const { data, status } = await api.get<User>("/users/1");

console.log(data.name, status);
```

`rest` devuelve `{ data, status, headers, response }`. El genérico describe el
JSON esperado; no valida los datos del servidor. Agrega un
[esquema](../guides/validation/) si necesitas validación en tiempo de ejecución.

`cache: false` crea un cliente independiente. Para compartirlo en tu aplicación,
sigue la [receta de cliente compartido](../recipes/shared-typed-client/).
Si omites `preset`, el predeterminado es `envelope`: usa `payload` en lugar de
`data` y comprueba las convenciones de error de la API. Consulta [presets](../guides/presets/).

## Maneja errores sin try/catch

Con el mismo `api`, llama a `safe.get` con los mismos argumentos:

```ts
const { data: result, error } = await api.safe.get<User>("/users/1");

if (error) {
	console.error(error.message);
} else {
	console.log(result.data.name);
}
```

Los métodos safe devuelven un resultado `data` con la forma del preset o un `Error`.
Siguen ejecutando la validación y los hooks de error. Los métodos normales rechazan
la promesa al fallar; consulta [errores](../guides/errors/) para inspeccionar errores
HTTP o usar `try/catch`.
